1. O que é Markdown?

Markdown é uma linguagem de marcação simples utilizada para formatar textos em arquivos .md.

Um arquivo Markdown pode ser criado com a extensão:

README.md


O arquivo README.md normalmente é utilizado para explicar um projeto, apresentar instruções e documentar seu funcionamento.

2. Títulos

Para criar títulos, utilizamos o símbolo #.

Quanto mais #, menor será o nível do título.

# Título 1
## Título 2
### Título 3
#### Título 4


Exemplo:

Título 1
Título 2
Título 3
3. Negrito e itálico
Negrito

Utilizamos dois asteriscos:

**Texto em negrito**


Resultado:

Texto em negrito

Itálico

Utilizamos um asterisco:

*Texto em itálico*


Resultado:

Texto em itálico

Também podemos combinar:

***Texto em negrito e itálico***


Resultado:

Texto em negrito e itálico

6. Imagens

A estrutura para inserir uma imagem é:

![Descrição da imagem](caminho-da-imagem.png)


Exemplo:

![Logo do projeto](img/logo.png)


A descrição entre [] é o texto alternativo da imagem.
